# 第五阶段：前后端 + 数据库三层架构实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将当前 Streamlit 一体式应用拆分为「FastAPI 后端 + Streamlit 前端 + SQLite/Chroma 数据库」三层架构，跑通端到端联调。

**Architecture:** 后端用 FastAPI 暴露 REST API（`/analyze`、`/search`、`/knowledge/*`、`/admin/rebuild-index`），复用现有 service 层；前端保留 Streamlit，改为纯 UI 层，通过 `httpx` 调用后端 API；数据库层保持 SQLite + Chroma 双存储不变，仅调整初始化时机为 FastAPI 生命周期钩子。

**Tech Stack:** Python 3.11 + FastAPI + Uvicorn + Pydantic v2 + httpx + Streamlit + SQLite + Chroma + DeepSeek + 通义千问 Embedding v4

## 一、教学定位（写在最前）

用户对后端开发和数据库完全没有系统学习过，本计划采用「边做边讲」策略。

**核心概念在开始前先讲清楚**：

1. **什么是后端**：后端是一个常驻运行的程序，监听某个端口（比如 8000），接收 HTTP 请求，返回数据。你可以把它想象成一个"函数电话总机"——前端打电话说"我要 /analyze"，后端就调对应的函数返回结果。

2. **什么是 REST API**：一种前后端约定好的通信规则。前端发 `POST /analyze` + JSON 数据，后端返回 JSON 数据。就这么简单。

3. **什么是 FastAPI**：Python 的后端框架。它做的事情就是把你写的普通函数用装饰器 `@app.post("/xxx")` 包一下，就自动变成 HTTP 接口，并且自动生成 API 文档页面。

4. **什么是数据库层**：现在项目里的 `knowledge_service.py` 就是数据库层——用 `sqlite3` 模块读写 SQLite 文件。第五阶段不换数据库，只是把数据库操作从 Streamlit 移到 FastAPI 里。

5. **为什么要拆分**：一体式的 Streamlit 应用无法多人同时使用，无法给医院其他系统调用。拆成前后端之后，未来可以：接入医院 HIS 系统、给移动端提供 API、多用户同时访问、独立部署到服务器。

```python
"""Pydantic schemas for request/response validation."""

from pydantic import BaseModel, Field


# ── Request models ─────────────────────────────────
class SearchRequest(BaseModel):
    query: str = Field(..., min_length=1, description="患者症状描述")
    top_k: int = Field(5, ge=1, le=20, description="返回结果数")


class AnalyzeRequest(BaseModel):
    query: str = Field(..., min_length=1, description="患者症状描述")
    top_k: int = Field(5, ge=1, le=20)


# ── Response models ────────────────────────────────
class FormulaItem(BaseModel):
    id: str
    name: str
    syndrome: str
    symptoms: str
    effects: str
    ingredients: str
    notes: str = ""
    category: str = ""
    source: str = ""
    similarity_score: float = 0.0


class FewshotItem(FormulaItem):
    example_case: str = ""


class SearchResponse(BaseModel):
    query: str
    top_k: int
    results: list[FormulaItem]


class AnalyzeResponse(BaseModel):
    query: str
    retrieved: list[FormulaItem]
    fewshot: list[FewshotItem]
    analysis: str
    pipeline_steps: list[str]


class KnowledgeCountResponse(BaseModel):
    sqlite_count: int
    chroma_count: int


class RebuildIndexResponse(BaseModel):
    sqlite_count: int
    chroma_count: int
    message: str
```

**讲解要点**：Pydantic 模型是"数据契约"——定义好请求进来该是什么形状、响应出去该是什么形状。FastAPI 会自动校验，如果前端传错了类型（比如 `top_k` 传成字符串），它会直接返回 422 错误，不用你手写校验。`Field(..., min_length=1)` 里的 `...` 是"必填"的意思。

```python
"""FastAPI lifespan events — startup/shutdown hooks."""

import logging
from contextlib import asynccontextmanager

from fastapi import FastAPI

from src.services.knowledge_service import sync_from_json, get_count
from src.services.retrieval_service import build_index

logger = logging.getLogger("uvicorn.error")


@asynccontextmanager
async def lifespan(app: FastAPI):
    """Initialize SQLite + Chroma on startup."""
    logger.info("Backend startup: syncing knowledge base...")
    try:
        sqlite_count = sync_from_json()
        chroma_count = build_index(force_rebuild=False)
        logger.info(
            "Knowledge base ready — SQLite: %d, Chroma: %d",
            sqlite_count,
            chroma_count,
        )
    except Exception as exc:
        logger.error("Knowledge base init failed: %s", exc)
        raise

    yield

    logger.info("Backend shutdown.")
```

**讲解要点**：`lifespan` 是 FastAPI 的启动/关闭钩子。之前 Streamlit 里用 `@st.cache_resource` 做的"首次启动时同步知识库"，在后端要挪到这里。`yield` 之前的代码是启动时跑，之后的代码是关闭时跑。

```python
"""POST /search — semantic retrieval endpoint."""

from fastapi import APIRouter

from backend.schemas import SearchRequest, SearchResponse, FormulaItem
from src.services.retrieval_service import search as retrieval_search

router = APIRouter(tags=["search"])


@router.post("/search", response_model=SearchResponse)
def semantic_search(req: SearchRequest) -> SearchResponse:
    """Perform semantic search over the TCM insomnia knowledge base."""
    raw_results = retrieval_search(req.query, top_k=req.top_k)
    results = [FormulaItem(**item) for item in raw_results]
    return SearchResponse(
        query=req.query,
        top_k=req.top_k,
        results=results,
    )
```

**讲解要点**：`APIRouter` 是 FastAPI 的"路由分组"——把相关接口放一个文件里，最后统一挂到 app 上。`response_model` 告诉 FastAPI 用什么模型序列化输出，自动生成的文档也会显示这个类型。

```python
"""POST /analyze — full RAG + Dynamic Few-shot pipeline endpoint."""

from fastapi import APIRouter, HTTPException

from backend.schemas import (
    AnalyzeRequest,
    AnalyzeResponse,
    FormulaItem,
    FewshotItem,
)
from src.services.retrieval_service import search as retrieval_search
from src.services.fewshot_service import build_fewshot_examples
from src.services.generation_service import generate_analysis

router = APIRouter(tags=["analyze"])


@router.post("/analyze", response_model=AnalyzeResponse)
def analyze(req: AnalyzeRequest) -> AnalyzeResponse:
    """Full pipeline: retrieval → dynamic few-shot → LLM generation."""
    try:
        retrieved = retrieval_search(req.query, top_k=req.top_k)
        fewshot = build_fewshot_examples(retrieved)
        analysis = generate_analysis(req.query, retrieved, fewshot)
    except RuntimeError as exc:
        raise HTTPException(status_code=503, detail=str(exc))
    except ValueError as exc:
        raise HTTPException(status_code=400, detail=str(exc))

    pipeline_steps = [
        "症状输入 → 文本预处理",
        "通义千问 text-embedding-v4 语义向量编码",
        f"Chroma 向量数据库余弦相似度检索 → Top {req.top_k}",
        f"动态 Few-shot 构建 → MMR 多样性选取 {len(fewshot)} 条参考医案",
```

```python
"""HTTP client for the FastAPI backend."""

import httpx

from config.settings import BACKEND_BASE_URL, BACKEND_TIMEOUT


class BackendError(RuntimeError):
    """Raised when the backend returns an error response."""


def _client() -> httpx.Client:
    return httpx.Client(base_url=BACKEND_BASE_URL, timeout=BACKEND_TIMEOUT)


def health() -> dict:
    with _client() as c:
        r = c.get("/health")
        r.raise_for_status()
        return r.json()


def knowledge_count() -> dict:
    with _client() as c:
        r = c.get("/knowledge/count")
        r.raise_for_status()
        return r.json()


def search(query: str, top_k: int = 5) -> dict:
    with _client() as c:
        r = c.post("/search", json={"query": query, "top_k": top_k})
        if r.status_code >= 400:
            raise BackendError(f"{r.status_code}: {r.text}")
        return r.json()


def analyze(query: str, top_k: int = 5) -> dict:
    with _client() as c:
        r = c.post("/analyze", json={"query": query, "top_k": top_k})
        if r.status_code >= 400:
            raise BackendError(f"{r.status_code}: {r.text}")
        return r.json()


def rebuild_index() -> dict:
    with _client() as c:
        r = c.post("/admin/rebuild-index")
        r.raise_for_status()
        return r.json()
```

**讲解要点**：`httpx.Client` 就是发 HTTP 请求的对象，`c.post("/xxx", json={...})` 会自动把字典变成 JSON 请求体。`raise_for_status()` 会在 4xx/5xx 时抛异常。这个文件是前端唯一"跨网络"的地方，Streamlit 里其他代码都只调这里的函数，不直接碰 HTTP。
